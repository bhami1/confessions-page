📚 Streamlit & Python Commands

Quick reference guide for Streamlit functions and Python CLI commands

📊 Streamlit Functions
Function Purpose
st.set_page_config() Sets browser tab title, icon, layout
initialize_database() Creates database tables
st.markdown() Displays text, HTML, CSS
st.sidebar Creates sidebar content
st.columns() Creates column layout
st.page_link() Creates navigation links
st.divider() Adds horizontal line
st.success() Shows success message
st.info() Shows info message
st.button() Creates clickable button
st.rerun() Refreshes the page
💻 Python CLI Commands
Command Purpose
cd folder_name Change directory to folder
py sample.py Run Python file
py -m venv .venv Create virtual environment
.venv\Scripts\Activate Activate venv if allowed
.venv\Scripts\python.exe Use venv Python
pip install -r requirements.txt Install all packages
streamlit run app.py Run Streamlit app
Set-ExecutionPolicy Change PowerShell security
